สวัสดี! เราเอง Puirkle 👋

ดีใจที่ได้แบ่งปัน **PuirkleQR** ให้ทุกคนใช้ โปรแกรมนี้สร้าง QR Code และบาร์โค้ดที่ปรับแต่งหน้าตาได้ตามใจ ใช้ได้ฟรีทั้งหมด **รวมถึงใช้ในเชิงพาณิชย์ด้วย** ไม่มีค่าใช้จ่ายแอบแฝง และไม่ต้องจ่ายเงินเพื่อใช้ฟีเจอร์ใด ๆ

ที่นี่คือช่องทางทางการของ PuirkleQR ทั้งไฟล์ดาวน์โหลด รายละเอียดการอัปเดต และการแจ้งปัญหา

## 📦 ดาวน์โหลด

เปิด **[เวอร์ชันล่าสุด](https://github.com/ResinCoreAI/PuirkleQR-Releases/releases/latest)** แล้วเลือกไฟล์ให้ตรงกับเครื่องของคุณ:

| เครื่องของคุณ | ไฟล์ที่ต้องดาวน์โหลด |
|---|---|
| 🪟 Windows (ติดตั้งลงเครื่อง) | `PuirkleQR-<เวอร์ชัน>-windows-installer.exe` |
| 🪟 Windows (ไม่ต้องติดตั้ง เปิดจากโฟลเดอร์หรือแฟลชไดรฟ์) | `PuirkleQR-<เวอร์ชัน>-windows-portable.zip` |
| 🍎 Mac ชิป Apple (M1, M2, M3, …) | `PuirkleQR-<เวอร์ชัน>-macos-apple-silicon-portable.zip` |
| 🍎 Mac ชิป Intel | `PuirkleQR-<เวอร์ชัน>-macos-intel-portable.zip` |
| 🐧 Linux (Ubuntu, Debian และดิสโทรตระกูลเดียวกัน) | `PuirkleQR-<เวอร์ชัน>-linux-installer.deb` |
| 🐧 Linux (ดิสโทรอื่น ๆ) | `PuirkleQR-<เวอร์ชัน>-linux-installer.run` หรือ `PuirkleQR-<เวอร์ชัน>-linux-portable.tar.gz` |

`PuirkleQR-FileServer.zip` ไม่ใช่ตัวโปรแกรม แต่เป็นเซิร์ฟเวอร์สำหรับ [QR ไฟล์](#-qr-ไฟล์) ซึ่งจะใช้หรือไม่ใช้ก็ได้

> [!TIP]
> ไม่แน่ใจว่า Mac ของคุณเป็นชิปอะไร? กดเมนู Apple → **เกี่ยวกับ Mac เครื่องนี้ (About This Mac)** ถ้าเห็น **Apple M…** คือชิป Apple ถ้าเห็นคำว่า **Intel** คือชิป Intel

**ดาวน์โหลดครั้งเดียวพอ** โปรแกรมอัปเดตตัวเองได้ เมื่อมีเวอร์ชันใหม่ ตอนเปิดโปรแกรมครั้งถัดไปจะถามว่า **"อัปเดตเลยไหม?"** และถ้าโปรแกรมมีอาการแปลก ๆ ใช้เมนู Studio → **ติดตั้งเวอร์ชันนี้ใหม่…** ได้ โค้ดและการตั้งค่ายังอยู่ครบ

## 🛠️ วิธีติดตั้ง

<details>
<summary><b>🪟 Windows</b></summary>
<br>

- **ตัวติดตั้ง:** เปิดไฟล์ `PuirkleQR-<เวอร์ชัน>-windows-installer.exe` แล้วทำตามขั้นตอน
- **แบบพกพา:** แตกไฟล์ `PuirkleQR-<เวอร์ชัน>-windows-portable.zip` ไว้ในโฟลเดอร์ไหนก็ได้ (หรือในแฟลชไดรฟ์) แล้วเปิด PuirkleQR จากโฟลเดอร์นั้น
- ถ้ามีหน้าต่างสีน้ำเงิน **"Windows protected your PC"** ขึ้นมา ให้กดลิงก์ **More info** ใต้ข้อความ แล้วกดปุ่ม **Run anyway** ด้านล่าง

</details>

<details>
<summary><b>🍎 macOS</b></summary>
<br>

1. แตกไฟล์ zip ที่ตรงกับชิปของเครื่อง (Apple หรือ Intel)
2. เปิด PuirkleQR
3. ถ้า macOS แจ้งว่าเปิดหรือตรวจสอบแอปไม่ได้ ให้ไปที่ **การตั้งค่าระบบ (System Settings) → ความเป็นส่วนตัวและความปลอดภัย (Privacy & Security)** เลื่อนลงด้านล่าง แล้วกดปุ่ม **Open Anyway** ที่อยู่ข้างข้อความเกี่ยวกับ PuirkleQR

</details>

<details>
<summary><b>🐧 Linux</b></summary>
<br>

แทน `<เวอร์ชัน>` ด้วยเลขเวอร์ชันในชื่อไฟล์ที่ดาวน์โหลดมา

**Ubuntu, Debian และดิสโทรตระกูลเดียวกัน (.deb)**

```bash
sudo apt install ./PuirkleQR-<เวอร์ชัน>-linux-installer.deb
```

**ดิสโทรอื่น ๆ (.run)**

```bash
chmod +x PuirkleQR-<เวอร์ชัน>-linux-installer.run
./PuirkleQR-<เวอร์ชัน>-linux-installer.run
```

**แบบพกพา (.tar.gz):** ไม่ต้องติดตั้ง แตกไฟล์แล้วเปิด PuirkleQR จากโฟลเดอร์ที่ได้

```bash
tar -xzf PuirkleQR-<เวอร์ชัน>-linux-portable.tar.gz
```

</details>

## ✨ ฟีเจอร์

PuirkleQR Studio สร้าง QR Code และบาร์โค้ดที่ปรับแต่งหน้าตาได้ตามใจ ใช้งานได้แบบออฟไลน์ มีภาษาไทยและอังกฤษ มีโหมดมืดและโหมดสว่าง

### 🔗 QR Code 24 ประเภท

- **เว็บและข้อความ:** ลิงก์เว็บไซต์ ข้อความ ลิงก์ดาวน์โหลดแอป (Google Play / App Store) ไฟล์ (PDF รูปภาพ เสียง วิดีโอ)
- **ข้อมูลติดต่อ:** vCard, MeCard, อีเมล, SMS, โทรออก, โปรไฟล์โซเชียล
- **แชต:** WhatsApp, LINE, WeChat
- **ประชุม:** Zoom, Google Meet, นัดหมายในปฏิทิน
- **สถานที่และเครือข่าย:** ตำแหน่งที่ตั้ง, Wi-Fi
- **การชำระเงิน:** พร้อมเพย์ (Thai QR), TrueMoney Wallet, PayPal, WeChat Pay, คริปโต
- **เพลง:** Spotify

### 🎨 การออกแบบ

- **รูปทรงโค้ด:** วงกลม หัวใจ สี่เหลี่ยมมุมมน แปดเหลี่ยม หกเหลี่ยม เพชร ดาว โล่ ดอกไม้ ตราสัญลักษณ์ กล่องคำพูด หมุดแผนที่ และเมฆ พร้อมเส้นขอบที่เลือกสีได้ หรือไม่มีขอบ
- **ลวดลายโค้ด 17 แบบ** กรอบตา 9 แบบ และลูกตา 13 แบบ
- **สี:** สีเดียวหรือไล่สีหลายสี กำหนดสีของตาแยกได้ พื้นหลังโปร่งใสหรือมุมมนได้
- **โลโก้ตรงกลาง:** ไอคอนในตัว 34 แบบ ตัวอักษรย่อ หรือรูปของคุณเอง
- **กรอบ 18 แบบ:** ป้าย "Scan me" กล่องคำพูด ตั๋ว โพลารอยด์ โทรศัพท์ Thai QR Payment แสตมป์ หรือใช้รูปของคุณเอง
- **ข้อความและสติกเกอร์:** วางข้อความและสติกเกอร์เคลื่อนไหวตรงไหนของโค้ดก็ได้
- **Picture QR:** ใส่รูปถ่ายหรือ GIF เคลื่อนไหวไว้ในโค้ด
- **สไตล์สำเร็จรูป 100 แบบ:** กดครั้งเดียวใช้ได้เลย รวมถึงหมวด "รูปทรง" และ "ธุรกิจ"
- **QR เคลื่อนไหว (GIF):** สีรุ้งไหล ไล่สีไหล และสลับสี

### 📊 บาร์โค้ด

Code 128, Code 39, Code 93, EAN-13, EAN-8, UPC-A, UPC-E, ITF, Codabar, PDF417, Data Matrix, Aztec

### 📚 สร้างหลายอันพร้อมกัน

- **QR หลายอัน:** แท็บ QR Code → เนื้อหา → **QR หลายอัน…** ข้อความ 1 แถว = 1 QR ใช้สไตล์ โลโก้ และกรอบเดียวกันทั้งหมด บันทึกเป็นไฟล์แยกลงโฟลเดอร์ที่เลือก
- **บาร์โค้ดหลายอัน:** แท็บบาร์โค้ด → **บาร์โค้ดหลายอัน…**
- พิมพ์รายการเองหรือนำเข้าจากไฟล์ `.txt` / `.csv` ได้ ตั้งชื่อไฟล์ตามข้อความในแถวหรือเป็นเลขลำดับ (`qr-001`, `qr-002`, …) และไม่เขียนทับไฟล์เดิม

### 🪪 สร้างบัตร

ออกแบบบัตรประจำตัว บัตรพนักงาน บัตรนักเรียน บัตรงานอีเวนต์ บัตรสมาชิก นามบัตร ป้ายชื่อ แล้วสร้างบัตรให้ทุกคนจากตารางรายชื่อ (พิมพ์เอง วางจาก Excel หรือนำเข้า CSV)

- กล่องแต่ละกล่องเลือกได้ว่า **คงที่** หรือ **แต่ละคน** ใส่ข้อความ รูป คิวอาร์โค้ด และบาร์โค้ดของแต่ละคนได้
- แม่แบบมากกว่า 20 แบบ ตั้งขนาดเองได้ หรือเริ่มจากรูปบัตรที่ออกแบบไว้
- แก้ไขแบบ Canva: ลาก ย่อขยาย หมุน จัดแนว เลเยอร์ พิมพ์บนบัตรได้เลย Ctrl+Z / Ctrl+C / Ctrl+V ซูม และโหมดโฟกัส
- สีตามระดับหรือตำแหน่ง (เช่น ระดับ A สีแดง B สีน้ำเงิน) เปลี่ยนข้อความ ซ่อน/แสดงกล่อง และเปลี่ยนสีรูปบัตรที่นำเข้าได้
- เลขรันอัตโนมัติ ตั้งคำนำหน้า ปี วันที่ หรือชุดตัวอักษรเองได้ พร้อมแบบสำเร็จรูป
- บันทึกโปรเจกต์ในโปรแกรมอัตโนมัติ ส่งออกเป็นไฟล์ `.pqrcard` ได้ บันทึกทุกใบเป็น PNG / JPG / SVG หรือสั่งพิมพ์ขนาดจริงพร้อมเส้นตัด

*การสร้างบัตรต้องใช้ License แพ็กเกจ Individual ขึ้นไป ขอฟรีได้ ดู [🔑 License ฟรี](#-license-ฟรี) ด้านบน*

### ✅ ตรวจการสแกน

โปรแกรมลองอ่านโค้ดทุกครั้งระหว่างที่คุณออกแบบ จึงรู้ได้ก่อนพิมพ์ว่าสแกนได้จริง

### 💾 บันทึก พิมพ์ แชร์

- **บันทึกเป็น** PNG, JPG, BMP, SVG (เวกเตอร์) หรือ GIF เคลื่อนไหว ขนาดสูงสุด 32,768 px สำหรับงานโปสเตอร์
- **ออกแบบหน้าพิมพ์:** วางหลายโค้ดในหน้าเดียว ทำแผ่นสติกเกอร์ จัดเรียงอัตโนมัติ รองรับ A3 ถึง A6 และอื่น ๆ
- **My QR:** เก็บโค้ดเป็นกลุ่ม กลับมาแก้ไขทีหลัง และนำสไตล์กลับมาใช้ซ้ำได้
- **แชร์:** คัดลอก อีเมล LINE, WhatsApp, Telegram, Facebook, X
- **ส่งไปยังคอมพิวเตอร์เครื่องอื่นของคุณ** ในเครือข่ายเดียวกัน ไม่ต้องใช้อินเทอร์เน็ต

### 💼 เวอร์ชันพกพา (Portable)

เปิดใช้จากโฟลเดอร์ได้เลยโดยไม่ต้องติดตั้ง ข้อมูลของคุณเก็บในไฟล์เดียวที่เข้ารหัสไว้และเปิดได้เฉพาะบนเครื่องของคุณ และมีปุ่ม **ย้ายไปเครื่องอื่น** สำหรับตอนเปลี่ยนคอมพิวเตอร์

### 📁 QR ไฟล์

QR Code ที่เปิดไฟล์ PDF รูปภาพ เพลง หรือวิดีโอ ไฟล์จะถูกอัปโหลดไปยังที่เก็บไฟล์ของคุณเอง ทั้งเซิร์ฟเวอร์ไฟล์ของคุณ หรือที่เก็บไฟล์แบบ S3 โดย `PuirkleQR-FileServer.zip` ที่อยู่ในทุก Release คือเซิร์ฟเวอร์ไฟล์ขนาดเล็กสำหรับ QR ไฟล์ ใช้ได้ทั้งบนเว็บโฮสติ้งที่รองรับ PHP หรือเป็น Cloudflare Worker
